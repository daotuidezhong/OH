## 本轮修复

- 已设置学期开始日期时，开学前的课程不再提前出现或发送提醒；增加对应规则回归。
- 手机空日程提示允许换行并限定宽度，消除窄屏横向溢出。
- 恢复后再次完成已领过奖励的任务时，提示“这项任务已领取过奖励”，避免误报当日奖励领满。
- 同步应用、npm 锁文件、应用内更新说明和版本断言为 `0.9.12`。
- 发布工作流监听当前分支，先生成草稿并上传全部安装包，再比对 GitHub 附件大小与哈希；拒绝覆盖已公开版本。

未提交的 pnpm 配置、设计记录、停用猫咪图集和 UI 图标未纳入发布提交。
