# v0.9.14 更新检查

本次包含猫咪动画的四组调整，以及此前已完成、尚未发版的像素图标与草莓飞入动画。

## 内容

- **素材比例**：8 方向行走图集按每只猫的单帧行走图统一缩放（按耳尖到脚底高度与头宽各半计算），对齐 idle 脚底线；打哈欠、洗脸整组按与 idle 的轮廓重叠横向对齐，睡觉、醒来对齐脚底。画布尺寸不变，不裁掉任何像素；idle 原图未改动，投喂骨骼坐标不受影响。处理脚本见 `scripts/normalize-cat-sprites.py`，原图备份保存在本地 `asset-backup/cat-sprites-2026-11-07/`，不进入 Git。
- **状态动画**：九段状态动画与状态切换不再使用走路帧或横向位移，纵向位移不超过 1px，时长统一为 90ms 的整数倍；新增挠抓姿势承担扑爪与张望。精力高 / 中时在静止 idle 中分别以 55% / 20% 的概率走到附近可直达的点，间隔至少 12 秒。
- **切换与静止**：移除姿势切换的半透明淡入和偏移过渡；新增 `cat-*-idle-breathe.png`（胸口和头上移 4 个源像素、脚部不动，由 `scripts/make-idle-breathe.py` 生成）作为呼吸帧；行走从每个方向双脚最靠拢的一帧起步，到站停留两拍再坐下。
- **行走运动**：`app/game/walk-motion.ts` 按整条路线规划加速、巡航（每秒 2 个猫宽）和减速；腿部帧按移动距离推进；长按方向键时延续当前速度与步伐相位。行走中位置直接写入 DOM，到站后写入一次存档；投喂、切换猫咪、切换场景时先停在当前位置。

## 验证

- 网页与 Worker 类型检查、`app desktop electron db tests worker` 的 ESLint、网页构建和桌面前端构建通过；自动测试 119 项通过（新增行走规划 3 项）。
- 素材：三只猫 41 个文件逐帧测量与对比图检查，归一化后各方向耳尖到脚底高度一致，无像素被裁掉。
- 浏览器（`vinext dev`）实测：状态动画 30 秒采样中原地走路帧 0 次、位移只有 0 / 1px，并观察到一次真实走动；呼吸帧切换、无透明度动画；行走 725px 用时约 2.7 秒，速度从 0 平滑升到约 285px/s 再降到 0，腿部帧约 90ms 一换，到站停在靠拢帧；长按右键持续前进、无回退，停下后位置保持。

预览窗格在后台时浏览器暂停了 `requestAnimationFrame`，行走类实测在页面内临时以计时器代替后完成，测后已刷新页面；未在可见窗口和桌面版中做最终画面验收。未提交的 pnpm 配置、设计记录、停用猫咪图集、新的 `cat-ginger-walk-8dir.png` 和 `public/game/ui-icons/` 未纳入发布提交。
