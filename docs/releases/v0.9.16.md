# OH v0.9.16

- 放映室重做成温馨的像素小影院：红色幕布、串灯、壁灯、书架上睡觉的小猫、放映机和两张红色扶手椅。B站画面直接放在大银幕上，银幕四周的光会随画面颜色变化；点击银幕放大观看，按 Esc 回到影院。
- 两人座位固定：创建放映厅的人坐右边（戴蓝色耳机的白色玩偶），加入的人坐左边（粉色蝴蝶结玩偶），两边看到的画面一致。对方上线时玩偶入座，离开时座位空出来。
- 聊天改为气泡：谁发的消息就冒在谁的玩偶头上；点“牵手”两只玩偶会牵起手来，头顶冒出爱心。
- 配对改为 6 位放映厅码：第一次进入时一人点“创建放映厅”，把左上角票根上的码发给对方，对方输入后点“加入放映厅”。配对一次以后打开放映室会自动入座，不用再填房间名和密码；想换房间点票根上的“更换”。
- 同步仍通过 VideoTogether 公共服务器进行，放映厅码、视频链接和播放进度会经过该服务器，视频本身不会。放映室继续使用独立的 B站登录，读不到游戏存档。

存档格式不变，猫咪位置、日记、日程与草莓照常保留。

Windows 使用 `Berry-Workout-Island-Setup-0.9.16.exe`，支持现有桌面版自动更新；Apple 芯片 Mac 使用 `OH-0.9.16-arm64.dmg`，Intel Mac 使用 `OH-0.9.16-x64.dmg` 手动安装。

本次继续沿用原应用身份与存档位置。macOS 安装包延续未签名、未公证的发布方式。
