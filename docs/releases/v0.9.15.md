# OH v0.9.15

- 新增放映室：房间里窗户和门之间靠墙放了一台复古电视柜，与唱片机柜同一条地面线，鼠标移上去屏幕会亮起并提示“进入放映室”，点击即可进入。
- 放映室在独立窗口直接打开 B站，可以登录自己的账号；内置“一起看”同步（VideoTogether）：两人在右下角面板填同一个房间名和密码，一人“建房”、一人“加入”，播放、暂停和拖动进度会自动同步，还能文字聊天。
- 放映室与游戏完全隔离：使用独立的 B站登录，读不到游戏存档和任何游戏功能；除全屏外不授予摄像头、麦克风等权限；B站以外的链接会用系统浏览器打开。
- 同步通过 VideoTogether 公共服务器进行，房间名、密码、视频链接和播放进度会经过该服务器，视频本身不会；房间密码请勿使用常用密码。

存档格式不变，猫咪位置、日记、日程与草莓照常保留。

Windows 使用 `Berry-Workout-Island-Setup-0.9.15.exe`，支持现有桌面版自动更新；Apple 芯片 Mac 使用 `OH-0.9.15-arm64.dmg`，Intel Mac 使用 `OH-0.9.15-x64.dmg` 手动安装。

本次继续沿用原应用身份与存档位置。macOS 安装包延续未签名、未公证的发布方式。
