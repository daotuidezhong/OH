# OH v0.9.11

- 新增默认空碗与完整投喂流程：起身、走到碗边、低头进食、抬头并恢复自主活动，吃完后碗恢复为空。
- 三只猫复用原始素材和体型，使用逐帧低头、咀嚼与抬头动作；修复猫头被碗和家具遮挡的问题。
- 草莓地毯等比例缩小至约 70%，优化家具碰撞、前后遮挡与绕行，防止连续点击和动作冲突。
- 修复桌面重复启动、存档导入缓存、跨日记录、日记分页及慢网草稿保存。
- 修复照片并发上传、说明文字编辑、大图遮罩关闭和离线睡眠结算。

Windows 使用 `Berry-Workout-Island-Setup-0.9.11.exe`，支持现有桌面版自动更新；Apple 芯片 Mac 使用 `OH-0.9.11-arm64.dmg`，Intel Mac 使用 `OH-0.9.11-x64.dmg` 手动安装。

安装包沿用原应用身份与存档位置。当前安装包未进行商业代码签名或 Apple 公证，首次运行可能需要在系统安全设置中确认。
