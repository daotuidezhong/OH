# OH v0.9.19

- 修复放映厅两台电脑网络环境不同时，各自连到不同的同步服务器、房间码一样也互相等不到对方的问题。两边现在固定使用同一台同步服务器（从 VideoTogether 的国内 CDN 配置取得，取不到时使用主服务器）。
- 放映厅左上角票根上显示当前同步线路（“国内线路”或“主线路”）。两台电脑显示的线路一致才能连上。

存档格式不变，猫咪位置、日记、日程与草莓照常保留。

Windows 使用 `Berry-Workout-Island-Setup-0.9.19.exe`，支持现有桌面版自动更新；Apple 芯片 Mac 使用 `OH-0.9.19-arm64.dmg`，Intel Mac 使用 `OH-0.9.19-x64.dmg` 手动安装。

本次继续沿用原应用身份与存档位置。macOS 安装包延续未签名、未公证的发布方式。
