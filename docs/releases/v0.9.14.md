# OH v0.9.14

- 猫咪八方向行走统一体型和落脚点：原先左右以外的六个方向比侧面大 16%–26%，转向时忽大忽小、脚底上下跳；现在按每只猫的坐姿统一大小，并对齐到同一条地面线。
- 打哈欠、洗脸、睡觉、醒来等动作与坐姿对齐，切换时不再横跳或上下跳；白猫躺下和起床时不再明显下沉。
- 原地状态改为扑爪、张望、洗脸、打哈欠等动作，不再踩着走路帧原地踏步或被整体抬起“腾空”；精力充沛的猫会不时真的在屋里走一小段，绕开家具，不打断正在播放的动作。
- 走路整条路线连续进行，起步加速、到站减速，转角不再停顿；迈腿跟随实际移动距离，不再滑步。到站后先收脚再坐下，长按方向键时持续前进。
- 静止时会轻轻呼吸（只抬起胸口和头，脚不离地）；动作之间直接切帧，不再半透明闪一下。
- 顶部状态栏和底部按钮换成像素图标；完成日记、专注或任务领取草莓时，草莓会从完成的位置飞入计数。

存档格式不变，猫咪位置、日记、日程与草莓照常保留。

Windows 使用 `Berry-Workout-Island-Setup-0.9.14.exe`，支持现有桌面版自动更新；Apple 芯片 Mac 使用 `OH-0.9.14-arm64.dmg`，Intel Mac 使用 `OH-0.9.14-x64.dmg` 手动安装。

本次继续沿用原应用身份与存档位置。macOS 安装包延续未签名、未公证的发布方式。
