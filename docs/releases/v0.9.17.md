# OH v0.9.17

- 放映厅右上角新增“离开放映厅”按钮（在“放大银幕”下方），点一下即可关掉放映厅回到游戏，游戏主窗口不受影响。
- 第一次进入放映厅的配对卡片上也可以选择“先不配对，离开放映厅”。
- 放映厅码长期有效：配对一次以后，每次打开放映厅都会自动回到同一个房间；只有点票根上的“更换”才需要重新配对。

存档格式不变，猫咪位置、日记、日程与草莓照常保留。

Windows 使用 `Berry-Workout-Island-Setup-0.9.17.exe`，支持现有桌面版自动更新；Apple 芯片 Mac 使用 `OH-0.9.17-arm64.dmg`，Intel Mac 使用 `OH-0.9.17-x64.dmg` 手动安装。

本次继续沿用原应用身份与存档位置。macOS 安装包延续未签名、未公证的发布方式。
