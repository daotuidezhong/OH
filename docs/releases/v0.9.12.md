# OH v0.9.12

- 墙上照片板升级为像素周日程本，每天分上午、下午和晚上，课程支持教学周、单双周重复、单次调课和停课，下课后自动粉碎。
- 任务可以拖动换天或时段、拖进碎纸机删除、放入完成文件夹归档；每项首次完成奖励 3 颗草莓，每天最多奖励 5 项，支持关联橙子专注与写进日记。
- 上课和有开始时间的任务提前 10 分钟提醒，桌面版在窗口最小化后仍可提醒。
- 使用自己的 DeepSeek API Key 截图导入课表，识别后逐行核对再导入；Key 单独保存在本机，不进入存档和完整备份。
- 食物碗支持自由摆放并记住位置，保留三只猫的可达性与投喂冲突保护。
- 更新像素信息栏与猫咪行走显示，减少行走过程中频繁写入桌面存档。

日程本替代旧照片板。升级时会清除旧照片板内容；日记与日记照片继续保留，旧版完整备份仍可导入。需要保留旧照片板的玩家请在升级前另存原图或保留旧备份。新日程随 `.ohbackup` 完整备份迁移。

Windows 使用 `Berry-Workout-Island-Setup-0.9.12.exe`，支持现有桌面版自动更新；Apple 芯片 Mac 使用 `OH-0.9.12-arm64.dmg`，Intel Mac 使用 `OH-0.9.12-x64.dmg` 手动安装。

安装包沿用原应用身份与存档位置。macOS 安装包延续未签名、未公证的发布方式。
