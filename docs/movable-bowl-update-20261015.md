# 下一次小更新：可移动食物碗

基于正式版 `v0.9.11`，本次先提交更新分支，不调整版本号或发布安装包。

## 更新内容

- 在现有布置模式中拖动食物碗，平时点击碗仍打开投喂入口。
- 合法松手后保存位置，刷新、重启和存档迁移后保留；旧存档使用默认位置，恢复布局也会恢复碗。
- 可以放在地板或地毯上；墙面、家具占用、底部操作区、猫咪站位不足和无法到达的位置会被拒绝。
- 拖动只预览位置，取消、失焦或丢失指针捕获时回退；投喂到抬头结束期间锁定碗。
- 投喂使用实际摆放位置，保持三只猫原有体型、素材、逐帧节奏及原有房间布局。
- 视口或家具布局变化时优先保留已保存位置，仅在原位置失效时寻找邻近可用位置。

## 验证

- 网页与桌面前端生产构建、网页及 Worker 类型检查、定向 ESLint 通过。
- 88 项自动测试通过，新增覆盖位置恢复、非法落点、三猫停靠与进食、不可达路径和家具可见占用。
- 桌面及 390×844 手机尺寸下的拖动、刷新保留、非法落点回退和恢复布局通过。
- 三只猫在移动后的碗边完成进食，每次只消耗一份食物并增加一次活力，结束后空碗且坐标不变；进食期间实际拖动被拒绝。
- 保留猫咪不可拖动的约束，原测试只限制猫咪节点，不再全局禁止其他物品使用指针捕获。

本次不新增依赖或图片素材。测试存档、草莓余额、临时核验入口、截图和构建产物不进入产品提交。
