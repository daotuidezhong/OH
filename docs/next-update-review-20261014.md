# 下一更新检查（2026-10-14）

基线：GitHub 正式版 `v0.9.10`。本次整理猫咪房间与投喂功能，并纳入本地尚未上传的存档、日记和照片板修复；保持房间布局及原有像素风格。

## 更新内容

- 猫咪和家具根据实际落地点动态排序，猫窝内休息与碗边进食有明确层级，碰撞采用家具的地面足迹。
- 草莓地毯等比例缩至原尺寸约 70%，新增默认空碗。
- 投喂使用独立状态机：起身、走向碗、对齐、低头、咀嚼、抬头、恢复自主活动。重复投喂、切猫、移动、布置和出门均有冲突保护。
- 三只猫复用各自原始素材及原始比例；低头三帧、两帧咀嚼循环、倒序三帧抬头，按约 180–230ms 的帧停留时间切换。
- 修复桌面重复启动与备份缓存混用、跨日记账、日记分页、慢网保存草稿、照片并发上传与说明光标、大图遮罩关闭、离线睡眠结算及多转折寻路。
- 增加网页/Worker 类型检查和下一更新 CI，覆盖网页构建、回归测试与桌面前端构建。
